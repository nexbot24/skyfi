# SKYi website redesign

Static redesign of skyi.co.uk. Same pages, URLs and content as the live site, with a new design.

- Content and page templates live in `build.py`; run `python3 build.py` to regenerate the HTML.
- Styles: `assets/site.css`, scripts: `assets/site.js`, images: `assets/img/`.
- Preview locally: `python3 -m http.server 4180` then open http://localhost:4180

Note: the contact form is front-end only and is not yet connected to a backend.
